# Writing tools and methods

A reference of the tools and methods developed with Claude across the Reptile House and Kestrel projects, extracted into one place so that other writing projects can refer to them. Two sets: **method** (how a novel project is organized and how a working session runs) and **craft** (instruments for the fiction itself, beginning with the rubric every beat and scene is scored by).

Everything here is a default. A project's constitution overrides it.

## Using this from another project

Add one line to the project's `CLAUDE.md`:

```
Shared writing tools and methods: /Users/mikel/repos/writing-projects/writing-tools/README.md — load on demand; the index there names the file for each tool. This project's constitution overrides any default there.
```

Then load by task:

| Task | Load |
|---|---|
| Setting up or reorganizing a project | `method/project-layout.md`, `method/outline-and-beats.md` |
| Opening or closing a session; ruling canon | `method/sessions-and-rulings.md` |
| Receiving a draft | `method/prose-review.md` |
| Building or consulting the pool of moments | `method/moment-trove.md` |
| Scoring a moment, beat, or scene; deciding what a passage is for | `craft/rubric.md` |
| Designing a story around astonishment; examining a synopsis | `craft/rug-pull-discipline.md` |
| Pacing the strange; public aftermath of a strange event | `craft/weirdness-management.md` |
| Magic, powers, backstory budget, the ladder of revelations | `craft/magic-and-metaphysics.md` |
| Act shapes, pivots, pacing devices, foreshadowing, POV | `craft/structure-and-pacing.md` |
| Casting, motivation, comic voice, protagonist design | `craft/character-and-comedy.md` |

## The entry format

Every tool is one `###` entry with these fields, in this order:

- **What.** One or two sentences: what the tool is.
- **When.** When it applies.
- **How.** The working content. Tables, checklists, and commands go here, inline.
- **Origin.** The project and date it emerged, and whose it was where that is recorded (the author's, or a derivation accepted without objection).
- **Scope.** One of: *General* (any long-form writing project); *Fiction*; *Genre (named)*; *Pattern* (a project-specific instance whose shape transfers; the instance is given as the example); *Series*; *General to this collaboration* (a rule about how the author and Claude work together).
- **See also.** Optional cross-references, by entry name and file.

Entries are written in plain language, readable on their own, in the same discipline the moment trove demands of its entries. When adding an entry, keep the format; when a tool changes in a project, update the entry here and note the date.
